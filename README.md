# nice_t4

Компонент ESPHome для приводов Nice по шине BusT4 (разработка, этап P1).

Состояние: готов кодек кадров, приёмный автомат, очередь запросов с таймаутами и постраничное чтение.
Компонент ESPHome (`__init__.py`, платформы, адаптер UART) ещё не написан, см. `docs/plan.md`.

## Проверка

```
make test   # сборка с -Wall -Wextra -Werror и sanitizers, 26 тестов
make gen    # пересоздать t4_registers.h, t4_cmds.h и tests/test_vectors.h из data/ и tests/vectors.json
```

## Состав

| Файл | Назначение |
|---|---|
| `components/nice_t4/t4_types.h` | константы и перечисления |
| `t4_frame.*` | кадр, XOR-суммы, сборка и разбор DEP и DMP |
| `t4_rx.*` | приёмный автомат с повторной синхронизацией |
| `t4_engine.*` | очередь запросов, пауза на шине, повторы, сопоставление ответов; интерфейс `Transport` |
| `t4_chunk.*` | постраничное чтение (RUN `18` и `19`) |
| `t4_registers.h`, `t4_cmds.h` | перечисления регистров и команд (генерируются) |
| `tests/vectors.json` | 159 проверенных кадров из спецификации протокола |

Лицензия не выбрана. Код написан по спецификации протокола, без копирования чужого кода.
